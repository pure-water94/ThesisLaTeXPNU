**빌드 수용시험 7건 통과**, **PDF 검사 35항목 통과**.

1. 익명 종합 예시: 컴파일 성공.
2. 미입력 메타데이터의 draft 시작본: 컴파일 성공, 공란/초안 표기 유지.

6. 과도하게 긴 표지 제목: 의도한 영역충돌 오류로 차단.

## 시각 검사

전19쪽을 이미지로 렌더하여 표지·백지·인준·목차·목록·두 초록·본문·표·그림·수식·참고문헌·부록의 잘림/겹침/제목 고립을 검수했다. 초록 본문은 가운데정렬이 아닌 양쪽정렬이다. 마지막 래스터 이미지 추가 후 바뀐 물리9쪽을 다시 검수했고, 나머지 페이지 이미지는 이전 검수본과 동일함을 파일 해시로 확인했다.

v0.2 학과 공통화 후 물리1/3/8/9/19쪽이 변경되어 재검수했다. 나머지 페이지 이미지는 앞서 검수한 결과와 동일했다. 공개 클래스와 빈 설정 예제에 실제 학과를 기본값으로 넣지 않았으며, 시험문서만 예시학과/Department of Example Studies를 명시한다.

익명 예시의 긴 국문 제목은 초록에서 단어 중간 줄바꿈이 나타날 수 있으나 누락/잘림은 아니다. 실제 제목 입력 후 의미 단위 줄바꿈과 길이를 별도로 조정한다.

## cm 간격의 판정 범위

코드에는 도식의 지정 간격을 반영했고 PDF 글자상자 좌표도 JSON에 보존했다. 그러나 공식 도식에는 기준선·잉크경계·상자경계 중 측정기준이 정의되어 있지 않다. 따라서 **프로젝트의 상자배치 구현과 실제 PDF 실측을 제공한 것이며, 모든 잉크경계 간격에 대한 학교의 최종 적합 판정을 대신하지 않는다.** 자세한 값과 기준은 compliance.md 참조.

## 해결한 실제 문제

- Tectonic musl 배포의 ICU 한글 줄바꿈 오류 → GNU 배포로 동일 시험 성공.
- `setstretch`가 현재 기본 크기를 다시 적용해 초록 크기를 바꾸던 순서 → stretch 설정 후 필수11bp를 적용하고 PDF에서 확인.
- 문서 draft 옵션이 hyperref/graphicx로 전파되어 링크/이미지를 억제하는 문제 → 메타데이터의 초안 표시와 링크/이미지 렌더 설정을 분리.
- bp 글자크기에 따른 Computer Modern 수식 크기 대체 경고 → fix-cm 적용.
- 하위 tests/에서 클래스 검색경로가 달라지는 문제 → 루트의 일회용 입력 래퍼로 시험.

## 남은 적용 조건

실제 원고 이식과 개인 학적정보 입력은 아직 하지 않았다. 영문 본문·석사·양면 인쇄·HWP 변환·제출기관 최종 승인도 이 검증에 포함하지 않는다. 입력 제목/이름/폰트가 바뀌면 다시 빌드하고 전체 PDF를 확인해야 한다. 표절·출처 적합성·학위종별·날짜의 사실성은 별도 인간 검토 사항이다.
