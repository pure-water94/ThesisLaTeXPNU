# 2026.9 부산대학교 지침 대응표

## 근거의 우선순위

1. [부산대학교 공식 논문 작성 지침](https://onestop.pusan.ac.kr/page?menuCD=000000000000302)에서 배포하는 **2026.9 학위논문 작성 준수사항**.
2. 같은 페이지의 공식 국문박사 HWP 템플릿: 본문 설정 등은 **편집 예시**, 강제 수치와 구별.
3. 지도교수·학과 확인 사항과 프로젝트의 편집 선택.

기준 PDF SHA-256: `8792e6b08145db2ec5d51c5968630eb30d9a9534823731023ee90e0e0f32ce84` (10쪽). 물리 p.4 공통사항, p.5 국문 서식 도식, p.8 체크리스트를 대조했다. 공식 PDF 자체를 이 저장소에 재배포하지 않는다.

학과는 공개 코드에서 고정하지 않는다. 각 사용자가 소속 학과의 공식 안내에서 확인한 국·영문 명칭을 `local-metadata.tex`에 입력한다. **학과명으로 학위종별·개인 학적 정보를 추론하지 않는다.**

## 필수 항목 → 구현·검증

- **A4 210×297mm / 표지 흑색** → geometry와 기본 흑색 텍스트. 예시 PDF 모든 용지 및 표지 글자색 검사. 초안 식별용 회색 안내는 final 모드에서 제거한다.
- **구성순서** → main.tex: 표지 → 백지면지 → 속표지 및 인준 → 목차 → 국문초록 → 본문 → 참고문헌 → 선택 부록 → 외국어초록. 표/그림목차는 공식 템플릿의 편집 예시를 추가 적용.
- **국문 작성 원칙** → 이 프로필은 국문 박사만 지원. 영문 본문을 사용하려면 지도교수 승인과 별도 영문 표지·인준 서식을 적용해야 한다. 현재 영문 본문/석사 호환을 주장하지 않는다.
- **표지** → 학위문구16, 제목22, 성명·대학원·학과·학위수여 연월16 PDF point. `PNUMakeCover`.
- **속표지/인준** → 제목22, 제출문·인준문16, 성명·소속·날짜·위원란14 PDF point. 지도교수14는 도식에 명시되지 않은 편집 선택. `PNUMakeApproval`.
- **위원란** → 위원장1+위원4. 실제 인명은 미입력 상태가 기본이며 서명·도장을 생성하거나 복제하지 않는다.
- **초록** → 제목14/성명12/소속11/요약·Abstract12/본문11 PDF point. 두 언어 모두 적용. 초록 본문은 양쪽정렬이며 제목의 가운데정렬과 분리.
- **초록 각각 2쪽 이내** → PNUAbstract가 쪽수를 계산하고 3쪽 이상이면 빌드를 실패시킨다. 2쪽 성공/3쪽 실패 시험 포함.
- **인준일** → 실제 최종심사 연월일을 입력. 날짜 자동 생성 없음. 표지 연월은 확정 학위수여 연월과 별도 필드.
- **참고문헌 표기** → 지도교수·분야별 작성법에 따른다. 이 구현은 natbib/unsrtnat 숫자형 첫 인용순 선택이며 학교 유일한 규정이 아니다. 샘플에 인용순서/서지 나열순서가 다른 시험을 넣었다.
- **표절방지 기준** → 템플릿이 검사·보증할 수 없다. 출처 귀속, 재사용 범위·출판사 조건, 인용 정확성은 작성자가 검토해야 하는 제출 전 필수 항목이다.
- **영문 제목 대문자 규정** → 영문으로 작성할 때 첫 글자 및 주요 단어의 첫 글자를 대문자로 쓰되 관사·접속사·전치사 예외. 고유명사/약어를 훼손할 수 있어 자동 강제 변환하지 않고 확인 항목으로 둔다.

## 도식의 cm 간격

클래스는 `inner sep=0`, `outer sep=0`인 **TeX 텍스트상자 경계**를 배치 기준으로 사용한다. 이 기준을 학교의 공식 측정 정의로 주장하지 않는다. 도식은 기준선/잉크경계/문단상자 중 측정 지점을 명확히 정하지 않았다. PDF 잉크경계 좌표도 검증 JSON에 보관한다.

### 표지

- 상단→학위문구45mm, 학위문구→제목20mm.
- 성명→대학원20mm, 대학원→학과5mm, 학과→연월20mm, 연월→하단40mm.
- 제목→성명은 도식 수치 미지정. 두 영역이 충돌하면 빌드 차단. 5mm 충돌 회피 기준은 프로젝트의 안전 여유이며 학교 규정이 아니다.

### 속표지 및 인준

- 상단→제목40mm, 제목→제출문15mm, 제출문→성명10mm.
- 성명→대학원10mm, 대학원→학과5mm, 학과→지도교수10mm.
- 인준문→날짜10mm, 날짜→위원란10mm, 마지막 위원→하단40mm.
- 지도교수→인준문, 위원 개별행간은 도식 수치 미지정. 클래스는 영역 충돌을 차단하며 위원 사이 간격은 편집 선택.

### 국·외국어 초록

- 상단→제목35mm, 제목→성명15mm, 성명→소속10mm.
- 소속→요약/Abstract15mm, 표제→본문10mm를 조판 상자/수직 간격으로 구현.
- 여러 줄 제목/소속의 내부 행간, 본문 행간·아래여백은 별도 편집 선택.
- 글꼴의 ascender/descender 때문에 **PDF 잉크경계 간격은 상자 간격과 같지 않다**. 코드의 숫자만으로 ‘모든 cm 공식 준수’를 판정하지 않는다. actual 제목/이름/서체를 넣은 최종 PDF 재검수 및 필요시 학교 확인이 남는다. 공식 허용오차를 새로 만들지 않는다.

## 선택 가능한 편집값

본문 UnBatang/TeX Gyre Termes 11bp, 좌우25/위35/아래25mm, 첫줄5mm, 문단뒤5bp. 장/절/항16/14/12bp, 앞부분 대문자 로마·본문1부터 아라비아, 아래중앙10bp. HWP180%와 LaTeX setstretch 값의 등가성을 주장하지 않는다. 지도교수 요구로 변경할 수 있지만 필수 앞표지/인준/초록 값을 함께 훼손하면 안 된다.

## 인쇄·디지털 적용 구분

- 2027년2월 졸업자부터 최종 논문은 도서관 dCollection에 디지털 파일 제출.
- 80g 이상 백색모조지, 회색 레자크 표지, 무사(선)철 제본, 등표지는 **인쇄본 제작 시 조건부 사항**. 디지털 PDF에 등표지를 강제 삽입하지 않는다.
- 인쇄 시 표지·면지·속표지/인준은 단면. 현재 문서 전체 oneside이므로 앞부분 단면 구조를 유지한다. 양면 제본 변형은 재검수 필요.
- 파일 형식/용량/보안/제출 기간 등 dCollection 세부 업로드 조건은 제출 시 공지를 확인한다.

## 제출 전 남는 사람의 확인

확정 학위종별·국영문 성명·학위수여 연월·실제 심사일·지도교수·위원5인, 실제 논문 본문과 양언어 초록, 주장-인용의 정확성, 표절/저작권, 학교 업로드 요건은 입력·확인이 필요하다. `approved=true`는 이 검토를 대신하는 자동 승인 값이 아니다. 실제 자료 없는 초안이 ‘제출 가능’으로 오인되지 않도록 `final` 가드를 유지한다.
