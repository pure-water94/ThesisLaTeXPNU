# 국문 박사 등표지 단독 출력

## 근거와 범위

[부산대학교 학생지원시스템 논문 작성 지침](https://onestop.pusan.ac.kr/page?menuCD=000000000000302)의 **「부산대학교 학위논문 작성 준수사항」 2026.9**, 인쇄쪽 3 / PDF 5쪽, 국문 `<서식1> 표지 및 등표지` 도식이 기준이다. 2026-10-06 재다운로드 파일은 기존 확보 지침과 SHA-256이 같았다.

- PDF SHA-256: `8792e6b08145db2ec5d51c5968630eb30d9a9534823731023ee90e0e0f32ce84`
- 보조 확인한 국문박사 HWP 가이드 SHA-256: `3618eedb348ff21d0db04f7646b08dfec18bf9234030159091e7787f3a8ab461`
- 공식 문서를 저장소에 재배포하지 않는다. 원문은 위 공식 페이지에서 확인한다.

국문 도식은 **글자를 세운 채 위→아래**, 제목이 여러 열이면 **오른쪽 열→왼쪽 열**로 읽는다. 위에서 제목, 성명, 학위수여년월 순서이며 상단과 하단은 각각 **2cm**, 제목–성명과 성명–년월 사이는 각각 **1cm**다. 날짜는 연·월이며 심사일이나 작성일이 아니다. 도식의 예시 연월을 실제 날짜로 자동 적용하지 않는다.

**책등 폭과 등표지 글자 크기는 이 도식에 명시되어 있지 않다.** 폭은 실제 제본 두께에 맞춰 제본소와 확인하고, 글자 크기와 제목의 열 나눔도 확인해야 한다. 둘 다 기본값을 확정하지 않으며 생략하면 컴파일이 실패한다. A4 표지의 가로폭을 책등 폭으로 사용하지 않는다. 출력 높이는 제본할 A4 책의 높이인 297mm이다.

지침은 등표지를 **책자(인쇄본) 제작 시 활용**하도록 안내한다. 전자논문 본문에 책등 페이지를 끼워 넣지 않는다. 이 클래스는 국문 박사 인쇄용 도식에 한정되며 석사·영문 등표지, 펼친 표지 전체, 재단선·도련·제본소 인쇄판은 구현하지 않는다.

## 사용

```sh
# 익명 시험: 폭/글자 크기는 오직 시험값이다.
python build.py --tectonic /path/to/tectonic --input spine-example.tex

# 개인 출력: 먼저 spine-metadata.example.tex를 local-spine.tex로 복사·작성
python build.py --tectonic /path/to/tectonic --input spine.tex
```

`local-spine.tex`는 기존 `local-*` Git 제외 규칙의 적용을 받는다. `spine-metadata.example.tex`는 개인정보 없는 빈 입력 양식이다.

| 필수 키 | 입력 |
|---|---|
| `width` | 제본소가 확인한 실제 책등 폭, 단위 필수 |
| `font-size` | 확인한 글자 크기, `bp` 등 단위 필수 |
| `title-columns` | 쉼표로 구분한 제목 열. **읽는 순서**, 즉 오른쪽 열부터 입력 |
| `author` | 성명 |
| `graduation` | 확인된 학위수여년월 `YYYY.M` 또는 `YYYY.MM` |

`\PNUspinesetup`으로 설정한 뒤 **문서 시작 전에** `\PNUspineGeometry`, 본문에는 `\PNUMakeSpine`만 한 번 호출한다. `spine.tex`가 이 순서를 제공한다. 자동 제목·이름 추측, 오늘 날짜 삽입, 다른 개인 원고 파일 자동 수집은 하지 않는다. 날짜값의 사실성 확인은 작성자 책임이다.

## 구현상 선택 — 학교 규정으로 오인하지 말 것

- 명시된 간격은 **TeX 문자 셀/상자 경계**를 기준으로 배치한다. 원문 도식은 잉크 경계 측정법을 정의하지 않았다. PDF 잉크 여백은 글꼴 메트릭만큼 다르므로 검증 보고서에 별도로 기록한다.
- 입력한 글자 크기의 1.3배 셀을 사용한다. 제목 각 열은 제목 상자 높이에 맞춰 글자 사이 여백을 균등 배분한다. 짧은 제목은 넓게 벌어질 수 있으므로 반드시 실물 크기로 검수한다. 제목 열 나눔과 글자 크기를 자동 축소·추정하지 않는다.
- 좌우 각 1mm는 **구현상 안전 여백**이지 공식 규정값이 아니다. 열이 폭에 들어가지 않거나 제목/성명/날짜가 높이를 초과하면 오류를 낸다.
- 일반 한글·숫자·문장부호의 문자 단위 세로 배열이다. 복잡한 수식·제어명령·혼합방향 영문 제목은 지원 대상으로 검증하지 않았다.
- `spine-example.tex`의 **20mm·12bp·2099.2·예시 이름/제목은 전부 익명 시험 입력**이다. 실제 폭·규정 글자 크기·사용자 학위일을 의미하지 않는다. 미리보기 PDF도 동일한 익명 시험 출력이다.
- PDF 제목은 일반적인 템플릿 제목, author 메타데이터는 공란이다.

## 실검증

`python verify_options.py`는 별도 1쪽, 시험 폭·높이, 열 순서·문자 방향, 날짜/성명, 2cm/1cm 배치와 상자 높이 합계, 글꼴 내장, 넘침/미해결 인용 등을 점검한다. 합격은 **해당 익명 시험에 대한 것**이며 실제 책등 폭 확정이나 학교 승인·제본 검수의 대체가 아니다.
